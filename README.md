# fabric-devops-example

An example repository for Microsoft Fabric DevOps workflows.

## Overview

This repo serves as a starting point for demonstrating DevOps practices with
Microsoft Fabric, including source control integration, deployment pipelines,
and CI/CD automation.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/roberts-andy/fabric-devops-example.git
cd fabric-devops-example
```
